# Usage
Run
```sh
infolang -h
```
for a detailed list of options that `infolang` accepts.

# Compiling
To compile, you need a working cargo installation. The recommended way to install cargo is via https://rustup.rs/. Once you have cargo installed, run
```sh
cargo build
```
or
```sh
cargo build --release
```
to build in release mode.
Cargo will place the compiled executable in the `target/` directory.
